# AutoMap-Navi-Assistant

一款为安卓车机设计的导航辅助悬浮窗工具。通过解析高德地图车机版（AmapAuto）的标准广播协议，实现导航信息、巡航数据与媒体播放的完美融合。

## 🚀 核心功能

### 1. 智能悬浮窗 (WindowManager 实现)
* **双模式自动切换**：根据高德广播状态，自动在 **导航模式** 与 **巡航模式** 之间切换。
* **极简/标准主题**：提供两种导航样式，支持实时缩放 UI，适配不同尺寸的车机屏幕。
* **数据全量解析**：
    * **导航态**：转向图标、剩余距离、剩余时间、路名、进度条、红绿灯倒计时。
    * **巡航态**：实时时速、当前路名、前方电子眼距离预警（电子狗）。
* **超速预警**：支持根据道路限速自动变色提醒。

### 2. 本地音乐播放器
* **智能歌词解析**：支持本地 `.lrc` 文件自动匹配。
* **编码自动识别**：解决中文歌词常见的 GBK/UTF-8 编码乱码问题。
* **UI 联动**：美观的播放控制界面与歌词滚动。

### 3. 系统级特性
* **自启动与保活**：支持开机自启，确保导航助手实时在线。
* **位置记忆**：自动保存悬浮窗位置，支持长按锁定，防止驾驶中误触。

## 🛠 技术栈
* **Core**: Java / Android SDK
* **UI**: Custom View, WindowManager, ObjectAnimator
* **Protocol**: AmapAuto Standard Broadcast Protocol (10001/60021/60073)
